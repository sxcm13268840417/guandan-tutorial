# 📦 QB编辑器 - 一键安装包说明

## 🎯 快速开始

### 最快的安装方式（仅需 3 步）

1. **下载项目**
   ```bash
   git clone https://github.com/sxcm13268840417/guandan-tutorial.git
   cd guandan-tutorial/multi-editor
   ```

2. **运行一键安装**
   - 双击 `快速安装.bat` （或 `一键安装.bat`）
   - 右键选择"以管理员身份运行"
   - 或使用 `python 一键安装.py`

3. **等待完成**
   - 脚本自动处理所有配置
   - 预计 15-30 分钟
   - 完成后自动启动安装程序

## 🐛 故障排查

### 脚本无法启动
**原因**: 需要管理员权限
**解决**: 右键 → 以管理员身份运行

### npm 安装失败
**原因**: 网络问题或缓存问题
**解决**: 脚本会自动清理缓存并重试

### 找不到 Node.js
**原因**: Node.js 未安装或 PATH 未更新
**解决**: 脚本会自动尝试安装，如失败请手动安装

### 构建失败
**原因**: 磁盘空间不足或权限不足
**解决**: 检查磁盘空间，重新以管理员身份运行
